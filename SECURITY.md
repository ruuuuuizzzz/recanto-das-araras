# Segurança

Esta distribuição é uma cópia de portfólio, sem banco real, backups ou credenciais locais. Não representa uma auditoria completa de segurança.

Não publique dados de moradores, documentos, placas, logs, senhas, tokens ou arquivos de configuração local. Os registros dos testes são exemplos sintéticos e não criam contas na instalação normal.

Para relatar uma vulnerabilidade, utilize o recurso privado de relato de vulnerabilidades do GitHub, caso habilitado pelo proprietário. Não exponha credenciais ou dados pessoais em issues públicas.

A configuração Docker incluída é destinada à execução local. Para disponibilizar uma demonstração na internet, revise autenticação e permissões, habilite HTTPS, use um banco exclusivo com dados fictícios e mantenha o MySQL inacessível pela rede pública. Nunca conecte esta demonstração ao banco do condomínio.
